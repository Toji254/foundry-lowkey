## Ordered implementation plan

1. **Phase 1A — safe send review (implementation committed; validation pending):** default to preview + confirmation, add RPC gas-estimate/fee context, add one-review batch handling for `--actors`, and preserve an explicit `--yes` automation escape hatch. No retries or implicit actor changes.
2. **Phase 1B — ABI display contract:** define a normalized decoder/rendering boundary for nested tuples, arrays, multiple outputs, events and custom errors; preserve raw payloads whenever decoding is incomplete.
3. **Phase 1C — output consistency:** inventory all user-facing Cast/Foundry wrappers and route common results through the shared renderer without breaking explicit JSON/raw modes.
4. Revisit audit journey, lab and walkthrough only where the audit finds concrete behavioral gaps.
5. Revisit Jevos/finding-specific AI only where live provider-boundary tests reveal a defect. Existing safe boundaries should be preserved, not rewritten.

Each phase needs focused regression tests, updated help/docs, exact-SHA CI, and installed-CLI/Anvil acceptance where applicable. This ledger must be updated with each verified phase; no feature becomes COMPLETE on compilation or help text alone.
